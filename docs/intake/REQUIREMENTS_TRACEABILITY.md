Le registre documentaire source comporte 55 entrées : racine 1 ; familles 8 ; entrées principales 24 ; groupes d’étapes 4 ; actions 12 ; vues 3 ; combinaisons 3. Les parents forment 54 liens ; les relations transversales sont au nombre de 28.

## Limites
La présence d’une technologie dans la base n’atteste pas son déploiement. Le prototype local ne prouve pas une installation dans ce dépôt. Les documents MCP datés de juillet sont des sources historiques. Les étapes de validation et la provenance de chaque disposition doivent rester explicites.
